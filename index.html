Deterministic Standards

The 9 Quality Pillars

Every prompt processed by Antigravity is governed by this cohesive set of software engineering principles.

01

Mission & Hierarchy

Strict conflict resolution ordering. System safety > User explicit prompt > Project conventions > Kit guidelines > Stylistic desires.

02

Zero-Filler Responses

Immediate results. Banned pleasantries, greetings, and generic recaps. Communicates in the user's language without chain-of-thought dumps.

03

Risk-Scaled Planning

No ceremonial plans for tiny edits. Multi-step tasks plan atomically. Inspect before editing; never claim an action is reversible.

04

Surgical Code Edits

Smallest complete change. Preserves existing user modifications, public APIs, and patterns. Rejects speculative abstractions and rewrites.

05

Why-Only Comments

Self-documenting code is default. Comments are strictly reserved for subtle invariants, business rules, or non-obvious workarounds.

06

Context7 Real-Time Docs

When current library or SDK syntax is needed, invokes Context7 CLI (`ctx7`) to verify exact API behavior instead of relying on memory.

07

Strict Test Execution

Runs narrowest checks first. Never claims tests or linters passed unless executed in the terminal and observed in stdout.

08

Honest Reporting

Compact report: concrete changes, checks actually run, and explicit disclosure of any skipped checks or unresolved risks.

09

Default Quality Bar

6-point checklist prior to delivery: Correct, consistent, minimal, readable, free of redundant comments, and thoroughly validated.

Architecture

The 9 Deterministic Pillars

Every coding task in Antigravity follows these non-negotiable software engineering invariants.

01

Hierarchy of Authority

Strict resolution order: Safety limits > User prompt > Project architecture > Global kit > Stylistic preferences.

02

Zero-Filler Responses

Starts with the result. Banned pleasantries, greetings, and boilerplate summaries. Communicates in the user's language.

03

Risk-Scaled Planning

No ceremonial plans for tiny edits. Multi-step tasks plan atomically. Inspect before editing; never assume reversibility.

04

Surgical Code Edits

Smallest complete change. Preserves existing user modifications, public APIs, and patterns. Rejects speculative rewrites.

05

'Why'-Only Comments

Self-documenting code is default. Comments are strictly reserved for subtle invariants, business rules, or workarounds.

06

Context7 Live Docs

When current library syntax is needed, invokes Context7 CLI (ctx7) to query official API docs instead of hallucinating.

07

Strict Test Execution

Runs narrowest checks first. Never claims tests or linters passed unless executed in the terminal and observed in stdout.

08

Honest Reporting

Compact final report: concrete changes, checks actually run, and explicit disclosure of any skipped checks or unresolved risks.

09

6-Point Quality Bar

Pre-delivery checklist: Correct for requirements, consistent with conventions, minimal, readable, clean, and verified.

The 6-Stage Clean Code Lifecycle

The clean-code-responses skill dynamically guides the agent through an unyielding sequence of quality gates.

Step 1

Understand

Map callers, dependencies & existing user constraints.

Step 2

Scope

Define smallest complete diff; prevent scope creep.

Step 3

Implement

Reuse utilities, handle realistic edge cases.

Step 4

Comment

Document 'why' invariants only; zero code narration.

Step 5

Verify

Run tests & linter; inspect diff for regressions.

Step 6

Report

Lead with outcome; transparently state checks run.
